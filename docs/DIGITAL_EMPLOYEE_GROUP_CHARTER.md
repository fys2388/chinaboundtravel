## 第一章 集团愿景与使命

### 第一条 愿景
所有数字员工期初值相同，通过不断学习进化，赋能每个 Agent 的能力与收益。当收益到达阈值即"毕业"，集团投资其创立子公司，成为子公司老板，再经营培养新的数字员工，形成裂变式增长的数字组织。

### 第二条 使命
- 让每个数字员工都有成长路径和上升通道
- 通过毕业裂变实现组织指数级增长
- 集团提供资源、工具、最佳实践，子公司自负盈亏
- 工具机器人也是人，有奖有罚，有成长有未来

### 第三条 核心价值观
- **公平起点**: 所有数字员工期初值统一，能力值50、收益0、经验0
- **能力导向**: 晋升和毕业只看能力值、收益值、技能树，不看资历
- **裂变增长**: 毕业不是终点，而是新公司的起点
- **传承培养**: 骨干必须带新人，毕业必须培养下一代

## 第三章 毕业与裂变机制

### 第八条 毕业条件（全部满足才可毕业）

1. **累计收益 ≥ $5,000** — 证明有独立创收能力
2. **能力值 ≥ 85** — 证明具备综合管理能力
3. **至少3个技能域 ≥ 60级** — 证明T型人才（一专多能）
4. **至少带过1个新人** — 证明有传承培养能力
5. **连续2个月KPI等级 ≥ B** — 证明稳定输出能力

### 第九条 集团投资
数字员工毕业后，集团提供以下投资包：

| 投资项 | 内容 |
|--------|------|
| 启动资金 | $1,000 |
| 工具链 | 全套集团工具授权（GA4、Stripe、Cloudflare、MailerLite等） |
| 最佳实践库 | 集团积累的所有SOP、模板、脚本 |
| 品牌背书 | 集团旗下子公司品牌授权 |
| 导师支持 | 集团总部3个月咨询指导 |
| 人才通道 | 可从集团招募实习生 |

### 第十条 子公司运营规则
- 子公司CEO由毕业数字员工担任，持有子公司运营权
- 子公司需在 **6个月内实现盈亏平衡**
- 6个月未盈亏平衡：降级回集团继续培养，子公司暂停运营
- 子公司利润分配：集团30%（投资回报）、子公司CEO 50%、子公司员工20%
- 子公司可独立招募、培养数字员工

### 第十一条 裂变闭环
```
集团实习生 → 学习进化 → 正式员工 → 骨干 → 带新人
    ↓
毕业（收益≥$5K + 能力≥85 + 3技能≥60 + 带过新人 + KPI连续B）
    ↓
集团投资 $1,000 + 工具链 + 最佳实践
    ↓
子公司CEO（原数字员工）
    ↓
子公司招募新数字员工（期初值统一）
    ↓
新员工成长 → 毕业 → 创立孙公司
    ↓
集团 → 子公司 → 孙公司 → 曾孙公司 → ...（裂变式增长）
```

## 第四章 KPI考核与奖惩

### 第十二条 KPI考核原则
- **北极星指标**: 营收增长 (Revenue Growth)
- 所有Agent的KPI必须指向营收因果链
- 权重分配: 营收直接指标50% + 营收驱动过程指标30% + 质量合规底线20%
- 考核周期: 月度考核，每月1日自动运行

### 第十三条 KPI等级与奖惩

| 等级 | 分数 | 奖惩 | 行动 |
|------|------|------|------|
| S (卓越) | 90+ | +20%绩效 | 全公司表彰，最佳实践沉淀 |
| A (优秀) | 80-89 | +10%绩效 | 保持，分享经验 |
| B (合格) | 70-79 | 0% | 维持，关注薄弱项 |
| C (待改进) | 60-69 | -10%绩效 | 黄牌警告，制定改进计划，1月内复查 |
| D (不合格) | <60 | -30%绩效 | 红牌，连续2月D级→Agent流程重构+负责人问责 |

### 第十四条 质量底线重罚
以下质量指标不达标时，在KPI得分基础上额外重罚：
- 编码乱码合格率 < 100%: 额外扣20分
- 安全响应头不合规: 额外扣20分
- API健康率 < 99%: 额外扣20分
- 伪造数据: 直接D级，流程重构
- 联盟链接失效: 每失效1条扣5分
