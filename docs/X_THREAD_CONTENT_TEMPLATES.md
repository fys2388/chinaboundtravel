## Thread模板结构

### 标准8条Thread模板

```
[1/8] 强钩子 + 痛点陈述
→ 用数字、反常识或强烈共鸣开头
→ 必须在280字符内抓住眼球

[2/8] 背景/问题展开
→ 为什么这个问题重要？
→ 数据支撑

[3/8] 核心方案/方法一
→ 第一个解决方案
→ 具体可操作

[4/8] 核心方案/方法二
→ 第二个解决方案
→ 与前面形成对比或递进

[5/8] 常见错误/避坑
→ 读者最容易犯的错误
→ 用"别做这个"制造紧迫感

[6/8] 进阶技巧/insider tips
→ 普通游客不知道的信息
→ 增加可信度和收藏价值

[7/8] 工具推荐/行动号召
→ 具体推荐什么工具/服务
→ 引导点击链接

[8/8] 总结 + CTA
→ 一句话总结全文
→ 引导关注/点赞/转发/点击链接
```
