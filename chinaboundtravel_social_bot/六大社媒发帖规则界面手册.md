## 1. Reddit

### 1.1 平台规则

**发帖入口**：`reddit.com/submit`（需登录态）

**允许的发帖类型**：
- `Link Post`：提交外部链接，Reddit 自动抓取 OG 信息生成预览
- `Text Post`：纯文本帖子，正文最多 40,000 字符

**外链规则（核心红线）**：
- ⚠️ **Text Post 正文中禁止直接粘贴外部 URL**（会被 Reddit 自动识别为"spam"降权或拦截）
- ✅ 合规方式：先发纯文本内容，在评论第一条（Comment）中补充外链
- `Link Post` 标题区允许带 URL，URL 会在标题下方自动显示为超链接

**社区（Subreddit）选择策略**：
- 主阵地：`r/ChinaTravel`（1.4万成员，活跃度高）
- 次阵地：`r/solotravel`、`r/backpacking`、`r/travel`、`r/CampingandHiking`
- 发帖前需先浏览社区规则（每个 Subreddit 的 Sidebar 可查看）

**标题规范**：
- 长度：30~300 字符
- 风格：疑问句 / 感叹句，激起好奇心
- 避免：全大写、过多emoji、明显的营销语气
- 示例：`"Just spent 7 days overlanding through Western Sichuan — here's what no one tells you"`

**风控要点**：
- 操作间隔：每次操作间隔 3~8 秒随机
- 同一 Subreddit 当日不超过 1 篇
- 禁止在多 Subreddit 同时发布相同内容（会被识别为spam）
- 发帖后等待 5 分钟再评论补充外链（模拟真人操作）

### 1.2 发帖界面要素

```
URL: https://www.reddit.com/submit
界面结构：
  ├─ [Title输入框]          ← 必填，30~300字符
  ├─ [url] [text] [quote]  ← Tab切换：Link模式 / Text模式
  ├─ [正文编辑区]           ← Text模式下填写纯文本（禁止直接URL）
  ├─ [Add a Poll]          ← 可选
  ├─ [Select Community]   ← 必选，点击弹出搜索框
  └─ [POST] 按钮           ← 底部蓝色按钮
```

**Text Post 流程（合规发帖）**：
1. 切换到 `text` tab
2. 填写标题
3. 填写正文（不包含任何 URL）
4. 选择 Community
5. 点击 `POST`
6. 等待 5 分钟
7. 在帖子下方第一条评论中补充外链（格式：`[Full guide here](https://chinaboundtravel.com/...)`）

### 1.3 内容模板（Western Sichuan 主题）

**正文**（纯文本，无URL）：

## 2. Pinterest

### 2.1 平台规则

**发帖入口**：`pinterest.com/pin/create/`

**内容形式**：Pin（图钉）= 1张图片 + 标题 + 描述 + 画板

**图片规范**：
- 建议尺寸：1000 × 1500 px（2:3 竖版，最佳表现）
- 最小尺寸：600 × 900 px
- 支持格式：JPG、PNG
- 文件大小：< 20MB
- ⚠️ 图片上不要有太多文字（Pinterest 算法会降低含文字过多图片的权重）

**标题规范**：
- 长度：最多 100 字符
- 放在图片上方显示在搜索结果中
- 风格：关键词 + 吸引力词
- 示例：`Western Sichuan Camping Guide: The Ultimate 7-Day Overland Route`

**描述（Description）规范**：
- 长度：500 字符以内（算法优先读取前 50 字符）
- 前 1~2 句：包含核心关键词（搜索引擎优化）
- 中间：描述内容价值
- 文末：CTA + 博客外链（可带 UTM 参数）
- 示例格式：
  ```
  The complete guide to planning a 7-day overland camping trip through 
  Western Sichuan, China. Includes route map, packing list, altitude tips, 
  and the best campsites. Full guide → https://chinaboundtravel.com/western-sichuan-camping 
  #ChinaTravel #Camping #Sichuan #OverlandAdventure
  ```

**标签（Board）规则**：
- 每个 Pin 必须归属一个画板
- 建议画板：`China Travel`、`Adventure Travel`、`Camping`、`Asia Travel`
- 可以同时添加到多个画板（最多 2~3 个）

**外链规则**：
- 每个 Pin 描述可带 1 个网站链接
- 链接会在 Pin 被保存时显示在来源字段
- Pinterest 会对所有外链进行 nofollow 处理（SEO 权重低，但可引流）

**日发上限**：约 10~20 篇/天（超过可能被限流）

### 2.2 发帖界面要素

```
URL: https://www.pinterest.com/pin/create/
界面结构：
  ├─ [拖拽/选择图片上传区]   ← 必填，支持拖拽上传
  ├─ [Where to save]       ← 画板选择（必选）
  ├─ [Title输入框]           ← 必填，100字符以内
  ├─ [Description]          ← 必填，500字符以内，含链接+标签
  ├─ [Destination Link]      ← 可选，关联外链
  └─ [Save] 按钮            ← 底部红色按钮
```

## 3. Quora

### 3.1 平台规则

**发帖入口**：`quora.com/answer/submit`（回答问题模式）

**内容形式**：问答（Answer）

**规则核心**：
- Quora 是**问答平台**，不是博客发布平台
- ✅ 合规方式：搜索相关问题 → 提交高质量回答
- 禁止：自问自答（会被识别为 spam）
- 禁止：明显的软文或硬广（账号会被降低权重）

**外链规则**：
- 回答正文中**可以**植入外链，但必须自然融入上下文
- 建议：文章链接放在回答最后，用 `[Source](URL)` 格式
- 同一回答中不要带超过 2 个外链

**内容风格**：
- 问答模式 = 解决问题型内容
- 开头直接回答问题（结论先行）
- 中间提供详细解释和个人经验
- 结尾：自然引导至博客链接
- 长度：300~1000 字回答效果最佳

**相关问题方向（Western Sichuan）**：
- `What is the best way to travel in Western Sichuan?`
- `Is it safe to camp in Sichuan, China?`
- `What should I know before traveling to Sichuan as a foreigner?`
- `How do I plan a road trip in Western Sichuan?`

**日发上限**：5 篇回答/天（过多会被限制）

### 3.2 发帖界面要素

```
URL: https://www.quora.com/answer/submit?dialog=question_composer
界面结构：
  ├─ [问题搜索框]           ← 顶部，填写问题的搜索框
  ├─ [回答编辑区]           ← 富文本编辑器
  │   ├─ [B] [I] [U]       ← 格式化工具
  │   ├─ [添加图片]         ← 可选
  │   ├─ [添加链接]         ← 可选
  │   └─ [添加视频]         ← 可选
  ├─ [Source]              ← 底部，可添加参考链接
  └─ [Submit] 按钮         ← 底部蓝色按钮
```

## 4. Medium

### 4.1 平台规则

**发帖入口**：`medium.com/new-story`

**内容形式**：长文（Article）

**登录方式**：
- ✅ Google 账号一键登录（fys2388@gmail.com）
- Chrome 调试浏览器已保持登录态

**标题规范**：
- 长度：建议 70 字符以内（SEO 友好）
- 可以有副标题
- 风格：数字 + 吸睛词（`7-Day Western Sichuan Camping: What No One Tells You`）

**正文格式**：
- Markdown 格式编辑器
- 支持标题（H1、H2、H3）、粗体、斜体、引用块、代码块、图片
- 段落间空行分开（按 Enter 两次）
- 引用块使用 `>` 符号

**标签（Tags）规则**：
- 最多添加 5 个标签
- 标签选择：travel、china、camping、adventure、sichuan
- 标签影响内容分发（选精准的，不要乱填）

**外链规则**：
- ✅ 正文任意位置可添加外链
- ⚠️ 同一篇文章中对外链接不要超过 3 个
- 建议在文末加 CTA：`If you found this useful, check out my full guide at chinaboundtravel.com`

**图片规范**：
- 宽度建议：1200px 以上
- 支持 JPG、PNG、GIF
- Medium 会自动优化图片加载速度

### 4.2 发帖界面要素

```
URL: https://medium.com/new-story
界面结构：
  ├─ [标题输入框]           ← 大字输入，H1级别
  ├─ [副标题输入框]          ← 可选
  ├─ [正文编辑区]           ← Markdown富文本编辑器
  │   ├─ [B] [I] ["] [🔗]  ← 格式化工具栏
  │   ├─ [+ ]              ← 插入图片/视频/代码
  │   └─ [T] [1"] ["] ["]  ← 标题级别选择
  ├─ [标签输入栏]           ← 下方，最多5个
  ├─ [Publish设置]         ← 右上角，可设置封面图
  └─ [Publish] 按钮        ← 右上角绿色按钮
```

## 5. Instagram（网页端）

### 5.1 平台规则

**发帖入口**：`instagram.com`（网页版，或 Creator Studio）

**登录方式**：
- fys2388@gmail.com 通过 Google 账号授权
- ⚠️ Instagram 网页端对自动化操作检测极严，**强烈建议仅作备选**

**内容形式**：图片 + 文案（最多 2200 字符）

**图片规范**：
- 建议尺寸：1080 × 1350 px（4:5 竖版）
- 最小：600 × 750 px
- 格式：JPG、PNG
- 每篇帖子最多 10 张图片

**文案（Caption）规范**：
- 前 125 字符最重要（算法读取）
- 结构：hook句 → 内容 → 标签 → 外链
- 标签：最多 30 个，#分隔
- 外链：Instagram 不允许在正文中直接点击（只能放主页 Bio 链接）

**⚠️ 重要限制**：
- 纯网页发帖（instagram.com）**无法直接上传图片**（需要通过 Creator Studio 或 API）
- 图片发帖只能通过 Instagram App 或 Creator Studio 网页版
- 网页版发帖仅支持纯文字动态（Reel/Story 也需要 App）

**风控要点**：
- 每次操作间隔 5~10 秒随机
- 不要频繁关注/取关/点赞（会被限流）
- 同一账号每日不超过 3 篇

### 5.2 发帖界面要素（网页版局限性）

```
URL: https://www.instagram.com/
网页版发帖限制：
  ✅ 可发布：纯文字动态（Text Post）
  ❌ 无法发布：图片帖子（需 App 或 Creator Studio）
  ❌ 无法发布：Reels

Creator Studio（推荐替代）：
  URL: https://business.facebook.com/creatorstudio
  ✅ 支持图片发帖
  ✅ 支持定时发布
  ✅ 支持 Instagram + Facebook 同步
```

**结论**：Instagram 发帖建议使用 **Facebook Creator Studio** 网页版代替。
