# 文章生成问题分析与优化计划

## 一、问题诊断

### 1.1 为什么10号以后网站没有新文章？

**根本原因：部署链断裂**

| 环节 | 状态 | 问题 |
|------|------|------|
| ✅ 博客生成器 | 正常运行 | 生成了文章到 content/posts/ |
| ❌ GitHub Actions | 被跳过 | commit message 包含 `[skip ci]` |
| ❌ Cloudflare Pages | 未部署 | deploy-cloudflare-pages.yml 检测到 `[skip ci]` 后退出 |
| ❌ 在线网站 | 无更新 | 新文章从未部署上线 |

**时间线：**
- 06-10: 文章生成 → commit 带 `[skip ci]` → 部署被跳过
- 06-11: 文章生成 → commit 带 `[skip ci]` → 部署被跳过  
- 06-12: 文章生成 → commit 带 `[skip ci]` → 部署被跳过
- 06-14: 修复完成 → 移除 `[skip ci]` → 自动部署触发

### 1.2 为什么文章深度不够？

**分析结果：**

| 指标 | 当前值 | 目标值 | 差距 |
|------|--------|--------|------|
| 文章字数 | ~1600 词 | 2500-3000 词 | 不足 |
| 章节深度 | 表面介绍 | 深度分析+实用信息 | 不足 |
| 个人故事 | 少量 | 丰富个人经历 | 不足 |

**根本原因：** AI 生成时的 `max_tokens` 限制导致内容被截断

---

## 二、解决方案

### 2.1 部署问题修复（已完成）

✅ 已修改三个 workflow 文件：
- `weekly-blog-update.yml`: 移除 `[skip ci]`，固定 Hugo 版本 0.147.0
- `deploy-cloudflare-pages.yml`: 移除 `[skip ci]` 检测，扩展 paths 监听
- `daily-inspection.yml`: 移除 `[skip ci]`，确保修复能触发部署

✅ 已推送至 GitHub，触发自动部署

### 2.2 文章深度优化（待执行）

**步骤1：修改博客生成器配置**

修改文件：`chinaboundtravel_social_bot/joran_blog_generator.py`

- 增加 `max_tokens` 从 2000 → 3500
- 增强 Prompt，要求更多深度内容和个人故事
- 添加章节深度要求（至少 5 个 H2 章节）

**步骤2：调整选题池**

修改文件：`config/topic_pool.json`

- 优先选择深度话题（如历史文化、深度攻略）
- 增加话题的详细程度要求

**步骤3：优化审核标准**

修改文件：`chinaboundtravel_social_bot/ai_editor.py`（如存在）

- 增加字数检查阈值（最低 2000 词）
- 添加章节深度检查
- 检查是否包含实用信息和个人经历

| 风险 | 影响 | 缓解措施 |
